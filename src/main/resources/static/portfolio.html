SITE STRUCTURE

サイトの構成

画面、API、データ、認証を役割ごとに分けて運用しています。

Frontend

ブラウザ画面

HTML・CSS・JavaScriptで、スマートフォンとPCの両方から操作できる画面を構成しています。

Backend

API・非同期処理

JavaのLambdaで予定、施設、チーム、試合、スタッツのAPIと画像解析処理を提供します。

Cloud

AWS・認証・データ

CloudFront、S3、DynamoDB、Cognitoを組み合わせ、認証されたメンバーだけがチーム情報を扱えます。
