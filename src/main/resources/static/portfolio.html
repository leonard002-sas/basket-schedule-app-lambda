ABOUT THE WORK

自分の暮らしから、アプリを考える

バスケサークルを運営する中で感じた不便や、婚約後の生活で必要になったことを出発点にしています。 自分で使いながら改善し、毎日の予定や準備が少し楽しく、豊かになることを目指しています。 個人開発だからこそ、AWSの利用量や処理方法も見直し、必要な機能をできるだけ低コストで運用することも大切にしています。

  • Java
  • JavaScript
  • HTML / CSS
  • AWS Lambda
  • DynamoDB
  • S3
  • CloudFront
  • Cognito
  • Gemini API
  • CodePipeline
SITE STRUCTURE

サイトの構成

画面、API、データ、認証を役割ごとに分けて運用しています。

Frontend

ブラウザ画面

HTML・CSS・JavaScriptで、スマートフォンとPCの両方から操作できる画面を構成しています。

Backend

API・非同期処理

JavaのLambdaで予定、施設、チーム、試合、スタッツのAPIと画像解析処理を提供します。

Cloud

AWS・認証・データ

CloudFront、S3、DynamoDB、Cognitoを組み合わせ、認証されたメンバーだけがチーム情報を扱えます。
